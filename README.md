# Manufacturing Sourcing Partners

Initial static website prototype for an international manufacturing sourcing consultancy.

## Local preview

Run any static web server from the repository root, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Updating the brand

All temporary brand values are held in `config/brand.js`. Update that file to change the company name, tagline, domain, contact email, logo reference, and main color palette across the site.
